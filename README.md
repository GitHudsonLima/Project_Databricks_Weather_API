Project Overview 

I developed a complete data engineering solution using Databricks for ingestion, processing, and analysis of real-time weather data consumed from the Open-Meteo API. 

The project was built following modern Lakehouse Architecture, Medallion Architecture, and ELT pipeline concepts, leveraging Python and SQL notebooks integrated with Delta Lake to ensure scalability, governance, and efficient data processing. 

The main objective of the solution is to automate the ingestion of weather data, process it through multiple analytical layers, and provide near real-time insights for dashboards and weather alert systems.
